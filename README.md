# ✨ 个人主页 · Apple 风格 + 可视化配置后台

## 🚀 快速开始

需要 **Node.js ≥ 20**。

### 方式一：一键脚本（推荐）

```bash
chmod +x start.sh
./start.sh
```

### 方式二：手动

```bash
npm install     # 安装依赖
npm run dev     # 开发模式: 前端 5173(热更新) + 后端 8787
# 或
npm run build && npm start   # 生产模式: 单服务 http://localhost:8787
```

启动后：

- **主页**：<http://localhost:8787>
- **管理后台**：<http://localhost:8787/admin>
- **初始密码**：自动生成，打印在启动日志中，同时保存在 `data/INITIAL_PASSWORD.txt`（首次登录后请在「账号与数据」中修改密码）

> 开发模式下前端跑在 <http://localhost:5173>（Vite 热更新，已代理 API），生产模式统一在 8787 端口。

## 🤖 智能助手（自带模型）

后台左侧「智能助手」是完整的配置向导，**需要你提供自己的模型 API**（密钥只保存在你自己服务器的 `data/assistant.json`，前端读不到完整 Key）：

1. **模型设置**：填写 API Base URL、API Key、模型名（任何 OpenAI 兼容接口），支持「测试连接」。
2. **简历导入**：上传或粘贴简历（支持 .txt / .md / .pdf / .docx），一键解析出完整站点配置——姓名、标题、介绍、经历、教育、技能、项目、联系方式、统计数字、推荐配色全部预置，预览确认后一键应用。
3. **配色助手**：内置 12 套设计师精选配色（无需模型），或让 AI 根据你的行业/风格生成 3 套高级配色；附配色小课堂（60-30-10 法则、主辅色搭配等）。
4. **使用指南**：四步上手 + 各版块配置说明 + 常见问题。
5. **AI 问答**：结合当前站点配置，回答任何使用问题。

> 服务端通过 OpenAI 兼容 `/chat/completions` 接口调用你的模型，自动兼容带/不带 `/v1` 前缀的 Base URL，并在模型不支持 JSON 输出时自动降级重试。

## 🗂 配置说明

所有内容都在管理后台左侧菜单中：

- **全局设置**：网站标题/SEO 描述/图标、明暗模式、主色/辅色、圆角、字号、版块顺序与开关、页脚
- **首屏 Hero**：徽章、姓名、大标题、副标题、头像、按钮、滚动关键词
- **关于我**：多段介绍、高亮要点、配图
- **数据统计**：数字卡片（自动滚动动画）
- **工作经历**：公司/职位/时间/地点/描述/标签（时间线展示）
- **教育背景**：学校/学位/时间
- **技能栈**：分组 + 熟练度进度条
- **项目展示**：名称/描述/封面/标签/ Demo 与 GitHub 链接（可选大卡片展示）
- **联系与社交**：邮箱/电话/位置/按钮/社交链接（github、x、weibo、bilibili、小红书、linkedin 等）
- **账号与数据**：修改密码、导出/导入配置、恢复示例内容
- **智能助手**：① 配置你自己的模型（任意 OpenAI 兼容 API：OpenAI / DeepSeek / Kimi / 通义 / 智谱 / 本地 Ollama）→ ② 上传或粘贴简历（txt/md/pdf/docx）一键解析并预置全部版块 → ③ 内置 12 套精选高级配色 + AI 按行业/风格生成配色 → ④ 使用指南与 AI 问答教你用好整套配置

## 📁 项目结构

```
个人主页/
├── server/          # Express 后端
│   ├── index.js     # API + 静态托管 + 图片上传
│   ├── store.js     # JSON 存储(原子写入) + 数据校验清洗
│   ├── auth.js      # scrypt 密码哈希 + HMAC 会话 + 限流
│   └── seed.js      # 默认示例内容(双语)
├── client/          # React 前端 (Vite + TS + Tailwind v4 + Framer Motion)
│   └── src/
│       ├── site/    # 主页(首页各版块)
│       ├── admin/   # 管理后台(登录/仪表盘/各版块编辑器)
│       └── components/  # 交互组件库(磁吸/倾斜/跑马灯/极光等)
├── data/            # 运行时数据(自动生成, 已 gitignore)
│   ├── site.json    # 你的全部配置
│   ├── auth.json    # 密码哈希
│   └── uploads/     # 上传的图片
├── start.sh         # 一键启动
└── package.json     # npm workspaces (server + client)
```

## ☁️ 部署到服务器

```bash
# 本机构建
npm install && npm run build

# 上传整个目录到服务器(排除 node_modules 可重新 install)
rsync -av --exclude node_modules ./ user@server:/opt/homepage

# 服务器上
cd /opt/homepage && npm install
PORT=8787 nohup node server/index.js > server.log 2>&1 &

# 可选: 用 nginx/caddy 反代 80 端口, 或 pm2 守护: pm2 start server/index.js
```

## 🛟 常见问题

- **忘记密码？** 删除 `data/auth.json` 并重启服务，会生成新密码。
- **想重置全部内容？** 后台「账号与数据 → 恢复示例内容」。
- **迁移/备份？** 拷贝 `data/` 目录即可（包含配置与图片）。
